# Пережити КПІ

2D-аркада про перший курс КПІ: створи свого студента, ходи кампусом, відвідуй пари-квізи, тримай баланс енергії, нервів і здоров'я та отримай залік у практика з матану в bullet-hell бою.

**Грати:** https://xiodet.github.io/kpigame/

## Керування
- Комп'ютер: WASD / стрілки — рух, E — дія, M — карта.
- Телефон: джойстик зліва (торкнись і тягни), кнопка дії справа.

## Як додати своє
Усе лежить в одному `index.html`, без збирання.
- Питання: блок `<script id="questions-data">` (поля `subject`, `topic`, `q`, `options`, `answer`, `explain`).
- Викладачі-боси: блок `teachers-data` (ім'я, вигляд, фрази).
- Випадкові події: блок `events-data`.

Прогрес зберігається в `localStorage` браузера.
